# AETHER / NOEMA v0.3 — material interaction pivot

v0.3 deliberately rejects the previous "AI sci-fi HUD" language.

## Removed
- cyan/purple neon dashboard composition
- fake telemetry as the main visual hook
- concentric HUD rings as the dominant motif
- button-driven effect playback

## New visual language
- near-black optical substrate
- brushed black metal and liquid-glass material
- a single warm slit as the only strong accent
- procedural refraction, caustics and material grain
- sparse identity text instead of dashboard data
- OpenGL ES 3.0 real-time fragment rendering

## Interaction model
- DOWN: object compresses and catches
- HOLD: energy builds; two tactile thresholds communicate charge
- DRAG: direct manipulation plus physical shear
- RELEASE: velocity transfers into inertia
- CHARGED RELEASE: central slit opens and the substrate temporarily splits before rejoining
- DEVICE TILT: low-amplitude parallax shifts the object in depth

The point is not utility. The point is to make the screen feel like a physical instrument rather than a generated technology dashboard.
