# AETHER Native

Zero-dependency Android build of the AETHER / NOEMA visual prototype.

- Framework-only Java + Android Canvas
- 60fps invalidate-on-vsync loop
- Accelerometer parallax
- Cinematic boot sequence
- Procedural orbital field and particles
- Haptic phase-collapse interaction
- No internet permission and no analytics

The GitHub Actions workflow builds a signed debug APK without Gradle or third-party libraries.
