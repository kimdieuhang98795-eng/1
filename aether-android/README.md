# AETHER // NOEMA

An Android-first visual prototype focused on motion, material, spatial depth, and "unknown but important" synthetic telemetry.

## What it does

Mostly looks expensive.

- Native Jetpack Compose UI
- Cinematic cold-start sequence
- Procedural synthetic core rendered with Canvas
- Device-tilt parallax using the accelerometer
- Haptic phase-collapse interaction
- Live orbital telemetry and mode switching
- No network permission, no data collection

## Build

```bash
gradle :app:assembleDebug
```

APK output:

`app/build/outputs/apk/debug/app-debug.apk`
